# Personal Portfolio — Shivshankar Gupta

A responsive personal portfolio site presenting my experience, education, skills, projects, and professional links.

**Live site:** [itz-shiva-29.github.io](https://itz-shiva-29.github.io/)

## Features

- Responsive layout with CSS animations
- Profile, experience, and education sections
- Technical skills and project highlights
- Resume and contact links

## Built with

HTML · CSS · JavaScript

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser.

The site is also published through GitHub Pages. The main page is `index.html`; static assets are in `assets/`.
